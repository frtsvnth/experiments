# Встроенные шрифты для PDF

Эти файлы нужны только для программной отрисовки PDF (кириллица не поддерживается
стандартными шрифтами jsPDF). Интерфейс использует те же гарнитуры с Google Fonts.

- `Manrope.ttf` — Manrope (variable, OFL-1.1), https://github.com/google/fonts/tree/main/ofl/manrope
- `CormorantGaramond.ttf` — Cormorant Garamond (variable, OFL-1.1), https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- `IBMPlexMono-Medium.ttf` — IBM Plex Mono Medium (OFL-1.1), https://github.com/google/fonts/tree/main/ofl/ibmplexmono
